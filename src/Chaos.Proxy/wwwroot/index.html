Chaos Proxy

Um proxy em .NET 10 + YARP que fica entre um cliente e uma API e injeta falhas de propósito: lentidão, timeout, erro 5xx, 429 com Retry-After, conexão derrubada e HTML no lugar de JSON. Serve para ver, com números, se o cliente aguenta.

Como funciona

  • Tudo que não começa com /_chaos é repassado para a API (aqui, uma API de demonstração embutida; no projeto, a API de Chamados em PHP).
  • As regras são avaliadas em ordem; a primeira que casa com a rota e passa no sorteio decide a falha. O sorteio e o relógio são injetáveis, então os testes são determinísticos.
  • Toda falha injetada sai com o cabeçalho X-Chaos-Fault. Uma falha real (a API fora do ar) vira 502 sem ele: teste e problema de verdade nunca se confundem.
